日期：2026-11-26

## 目标

在现有缠论 K 线、结构买卖点和技术指标体系上，增加四类互补信息：

1. **VWAP / Anchored VWAP**：观察盘中成交成本和结构锚点成本。
2. **布林带宽度 + 突破**：观察波动收缩、扩张和收盘突破。
3. **RSI 背离**：辅助识别顶部动能衰减和底部动能改善。
4. **相对强弱 RS**：判断个股相对 QQQ 或 SPY 的强弱，而不是把它误认为资金流。

设计原则：复用现有 OHLCV、RSI、基准历史和缓存机制；默认关闭新图层；主图只保留必要线条和少量事件标记；形成中的 K 线可以显示观察状态，但最终信号必须区分收盘确认状态。

## 阶段 1：VWAP / Anchored VWAP

状态：**已完成（2026-11-27，Codex）**

股票与期货页均可独立开启两条线。锚定值从最近的已确认笔或线段端点累计，于确认时开始显示。盘中尾值采用已取得的 15 分钟行情，标记为形成中观察。专项测试通过，覆盖跨日、零成交量、缺失 K 线、提前收盘、盘中尾值、平移缩放和偏好恢复。盘中 VWAP 按当前图表周期的典型价格计算，周期不同会产生不同的成本估计。

前置：阶段 0
计划产出：`OptionScopeVwap` 计算模块、主图模型字段、主图绘制和独立开关。

### 规则和范围

- **Session VWAP**：仅在盘中周期使用，按美股常规交易日重置；使用典型价格和成交量累计计算。
- **Anchored VWAP**：支持从已确认的缠论结构锚点开始计算，初版锚点优先使用已确认笔/线段端点；用户手动选择锚点作为后续增强项，不能把未确认的未来枢轴当作锚点。
- 日线和周线不显示伪装成“当日成本”的 Session VWAP；没有合适锚点或成交量无效时显示不可用状态。
- 形成中的 K 线允许更新当前 VWAP 值，但不改变已经完成交易日的历史结果。

### UI 和验收

- 主图叠加细线，不改变 K 线价格范围；VWAP 与 Anchored VWAP 使用不同线型或颜色。
- 不为每根 K 线添加文字，只在锚点和当前值处提供简短说明。
- 覆盖跨交易日重置、零成交量、缺失 K 线、盘中实时尾值、缩放/平移和偏好持久化测试。

## 阶段 2：布林带宽度 + 突破

状态：**已完成（2026-11-27，Codex）**

带宽收缩采用此前最多 120 个已收盘带宽的第 20 百分位，至少需要 40 个样本。观察标记空心，收盘确认标记实心。同一方向连续越界只记首次，回带后允许新的突破。已通过布林带计算、无效行情、盘中尾值、视口和图表偏好专项测试。

前置：阶段 1
计划产出：布林带计算、带宽序列、收缩状态和突破事件。

### 规则和范围

- 默认参数为 **20 期、2 倍标准差**，中轨使用 20 期均线。
- `带宽 = (上轨 - 下轨) / 中轨`；收缩采用历史滚动分位或明确阈值，必须固定参数并写入模型说明。
- 上破/下破只在收盘确认后成为正式事件；形成中的 K 线只显示观察状态，不能提前画成已确认买卖信号。
- 上下轨、带宽和突破状态必须按完整历史序列计算，再切片到可见窗口，避免平移或缩放改变结果。

### UI 和验收

- 上下轨和中轨属于主图覆盖层；带宽和收缩状态属于副图或紧凑状态栏，不能再压缩价格区。
- 突破只显示关键标记，连续同方向事件需要去重或合并。
- 覆盖样本不足、标准差为零、无效 K 线、突破后重新回带、形成中 K 线和视觉拥挤回归测试。

## 阶段 3：RSI 背离

状态：**已完成（2026-11-27，Codex）**

对当前周期使用与趋势摘要同口径的 Wilder RSI(14)。用左右各两根 K 线确认价格和 RSI 枢轴，允许两者相差两根，最多比较相距 60 根的相邻有效配对。形成中的末根只产生观察信号。后续收盘 K 线的极值穿过信号枢轴后标为失效。已通过顶底背离、去重、失效、形成本根、跨周期和逐根前缀回放测试。

前置：阶段 2
计划产出：可复用 RSI 序列、顶/底背离事件、副图绘制和说明文案。

### 规则和范围

- 复用现有 RSI(14) 的口径；不同周期按当前 K 线周期计算，不能把日线 RSI 直接套到 1 小时图。
- **顶背离**：价格确认更高高点，而 RSI 确认更低高点；**底背离**：价格确认更低低点，而 RSI 确认更高低点。
- 价格枢轴和 RSI 枢轴都必须在可见确认条件满足后才产生正式事件；形成中的 K 线只允许显示“观察中”。
- 不允许使用未来 K 线回写历史信号；背离事件需要唯一 ID、确认时间和失效条件。

### UI 和验收

- RSI 放在副图，保留 30/50/70 参考线；背离只显示一条连接线和一个简短标签。
- 不与 AF StochZ、MFI 同时大量显示重复的超买超卖文字；默认只显示 RSI 线和背离标记。
- 覆盖顶/底背离、多次尝试去重、信号失效、实时尾值、跨周期和无未来函数回放测试。

## 阶段 4：相对强弱 RS（QQQ / SPY）

状态：**已完成（2026-11-27，Codex）**

股票和期货页共享基准选择。自动模式用 SPY 比较 QQQ 和一般标的，用 QQQ 比较 SPY、纳指指数、纳指期货与指定纳指 ETF。手动选择随浏览器保存。以当前窗口首个共同时间点归一化为 100，严格匹配日线交易日、周线结束日或盘中时间戳。仅在双方同期 K 线均形成中时更新观察值。基准缓存为空或时间不重合时留空。已通过 Node 对齐、窗口、实时尾值、切换与缓存测试，以及 Go 日周线、盘中、价格口径和缺失数据测试。

前置：阶段 3
计划产出：基准选择、时间对齐、RS 序列、强弱状态和副图绘制。

### 规则和范围

- 计算目标标的价格相对基准价格的比值，并在当前显示窗口起点归一化为 100。
- 基准可在 **QQQ** 和 **SPY** 之间切换；默认值需要在实现阶段结合标的类型决定，不能假设所有股票都适合同一个基准。
- 日线按交易日对齐；盘中按时间戳对齐，只使用双方都存在的 K 线。缺失基准数据时显示“基准数据不足”，不能用 0 填充。
- 强弱上升/下降是相对表现，不表示资金流入/流出，也不直接生成买卖点。
- 形成中的 K 线可实时更新当前 RS，但历史 RS 只能由当时可见的目标和基准 K 线计算。

### UI 和验收

- RS 放在副图，显示归一化基线 100；可选显示基准名称和当前相对变化。
- 强弱事件只保留“跑赢/跑输切换”等关键状态，避免逐 K 线文字。
- 覆盖 QQQ/SPY 切换、日期和盘中时间对齐、缺失数据、基准缓存更新、日线/盘中和实时尾值测试。

## 暂不纳入本轮

- **KDJ / 普通随机指标**：和 AF StochZ、MFI 的动量/超买超卖功能重叠。
- **EMA 彩带和一目均衡表**：主图线条过多，和 MACD、SMA200、SuperTrend、葛兰碧重复。
- **CVD、Footprint、主动买卖盘**：当前 Yahoo/Alpaca K 线不包含可靠的逐笔买卖方向，不能从普通成交量直接推导。

## 首版规则

- 锚点采用已确认的笔或线段端点。手动点选留待后续增强。
- 布林带收缩采用历史滚动分位，窗口与预热样本数见阶段 2。
- RS 默认按标的类别选基准，支持手动覆盖。
